# CyKrome Launcher v1.1.0 Release Notes

## 🎉 New Features

### App Drawer Enhancements
- **Search Functionality**: Added comprehensive search bar in app drawer with real-time filtering
- **Search Results UI**: Beautiful search results display with app suggestions and text suggestions
- **Tab Navigation**: Improved letter-based tab navigation with dark blue background
- **Selected Tab Highlighting**: Cyan-colored box highlights the currently selected letter
- **Auto-Centering**: Selected tab automatically scrolls to center for better visibility
- **Back Button Handling**: Smart back button behavior - clears search instead of closing drawer when search is active

### Home Screen Improvements
- **Dock Search Integration**: Dock search bar now opens app drawer search for seamless experience
- **Page Indicators**: Added page indicators above dock for better navigation
- **Glance Page**: New swipe-left page with cards for weather, calendar, and contacts
- **Search Bar in Glance**: Integrated search functionality in the Glance page

### UI/UX Enhancements
- **Dark Blue Theme**: App drawer tabs now feature a modern dark blue background (#1E3A5F)
- **Cyan Selection Indicator**: Selected letters are highlighted with a cyan box for better visibility
- **Improved Spacing**: Better spacing and padding throughout the app
- **Smooth Animations**: Enhanced animations for drawer opening/closing and page transitions

## 🔧 Improvements

- **Removed Search Overlay**: Replaced home screen search overlay with integrated app drawer search
- **Better Permission Handling**: Improved storage and media permission requests
- **Wallpaper Display**: Fixed wallpaper centering and display issues
- **Status Bar Padding**: Restored proper top padding to prevent content overlap

## 🐛 Bug Fixes

- Fixed search overlay cursor blinking issue (documented as known issue)
- Fixed drawer tab visibility issues
- Improved back button handling in search
- Fixed wallpaper image cropping and centering

## 🚀 Installation

1. Download the APK from the releases page
2. Enable "Install from Unknown Sources" if needed
3. Install the APK
4. Set CyKrome Launcher as your default launcher when prompted

## 📝 Known Issues

- Search overlay cursor blinking after keyboard dismissal (documented in PROJECT_STATUS.md)
- Some edge cases with first/last tab centering may need refinement
